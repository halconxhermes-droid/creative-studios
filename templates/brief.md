# Creative Studios — Plantillas de Artefactos

## `brief.md` — Input del usuario

```markdown
---
titulo: <título tentative>
formato: <novela / manga / comic / video / noticia>
publico-objetivo: <edad / intereses>
tono: <noir / comedia / optimista / épico>
longitud: <palabras o páginas>
referencias-obligatorias: <urls o títulos>
restricciones: <palabras prohibidas, temas sensibles, formato máximo>
---
```

## `pitch.md` — Sinopsis de 1 página

```markdown
# Pitch: <título>

**Premisas clave (3):** <lista>
- <premisa 1>
- <premisa 2>
- <premisa 3>

**Conflicto principal:** <descripción en 2-3 oraciones>

**Protagonista:**
- Nombre: <nombre>
- Motivación principal: <por qué hace lo que hace>
- Obstáculo interno: <conflicto personal>

**Gancho emocional:** <qué hará que el lector/viewer se implique>

**Arco propuesto:**
- Inicio: <status quo>
- Punto de no retorno: <qué obliga al cambio>
- Clímax: <confrontación decisiva>
- Resolución: <nuevo status quo>

**Tono por escena:**
- <escena tipo>: <tono>
